Example tool

This is where an interactive HTML tool lives. To replace it:

  1. Save your artifact's HTML as index.html in a new folder under tools/.
  2. Add an entry for it in assets/js/tools.js.
  3. Commit and push in GitHub Desktop. The site updates in about a minute.

Tip: add a "Back to all data tools" link at the top of each tool so visitors can find their way home.
